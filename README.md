# بوابة طالب كلية الزراعة — Android / Kotlin

مشروع Android Studio مبدئي قابل للتطوير، بواجهة عربية RTL.

## المميزات الموجودة
- شاشة تسجيل دخول باسم مستخدم وكلمة مرور.
- أول تشغيل ينشئ بيانات دخول محلية للتطبيق على الجهاز.
- تخزين كلمة المرور بصيغة مشتقة PBKDF2-HMAC-SHA256 مع Salt عشوائي؛ لا يتم حفظ كلمة المرور الأصلية.
- دخول بالبصمة باستخدام AndroidX BiometricPrompt.
- تسجيل البصمة يتم من إعدادات أندرويد الرسمية، ولا يقرأ التطبيق صورة البصمة أو يخزنها.
- صفحة رئيسية بها كروت الروابط الستة المطلوبة.
- فتح الروابط داخل التطبيق باستخدام WebView مع منع الوصول إلى ملفات الجهاز ومنع اتصالات HTTP غير المشفرة.
- بطاقات توضيحية لمشكلة تحديد المنصة، وجروب Telegram، ومواعيد وحدة IT.

## تشغيل المشروع
1. فك ضغط الملف.
2. افتح مجلد `AgriStudentPortal` في Android Studio.
3. استخدم JDK 17، واسمح لـ Android Studio بتنزيل Gradle والاعتماديات.
4. ثبّت Android SDK Platform 35 عند طلبه.
5. شغّل التطبيق على هاتف Android أو محاكي.

## تنبيه مهم عن تسجيل الدخول
النسخة الحالية تنفذ **قفلًا محليًا للتطبيق فقط**. في أول تشغيل، أول اسم مستخدم وكلمة مرور يتم إدخالهما يصبحان بيانات الدخول المحلية لهذا التطبيق. هذا لا يتحقق من صحة حساب ابن الهيثم أو حساب الجامعة، ولا يرسل بيانات الدخول إلى الكلية.

لجعل شاشة الدخول تتحقق من حساب الطالب الجامعي فعلًا، يلزم API رسمي أو آلية مصادقة موثوقة من الجامعة. لا ينبغي محاولة جمع كلمة مرور الطالب أو تمريرها إلى خادم غير رسمي.

## ملاحظات البصمة
- لا يمكن للتطبيق إضافة بصمة إلى الهاتف بنفسه؛ أندرويد يدير تسجيل البصمات في إعدادات الأمان.
- يلزم أن يكون الهاتف يدعم `BIOMETRIC_STRONG` وأن تكون بصمة مسجلة بالفعل.
- عند عدم وجود بصمة مسجلة، يحاول التطبيق فتح شاشة تسجيل البصمة في إعدادات الجهاز.

## ملاحظات WebView
الروابط تُفتح داخل التطبيق افتراضيًا. بعض الخدمات مثل Outlook أو Facebook قد تقيّد تسجيل الدخول داخل المتصفح المضمّن لأسباب أمنية؛ في هذه الحالة قد تطلب الخدمة فتحها في متصفح النظام.
